# Data Analysis Dashboard

A browser-based dashboard for exploring CSV and Excel datasets. It includes data quality checks, cleaning tools, summary statistics, correlations, interactive charts, filters, and exports. Data analysis runs in the browser.

## Try it

Live demo: https://oberhirisimeon.xo.je/dashboard/

## Run locally

Open `index.html` in a modern browser. The core dashboard works without cloud configuration. Optional cloud features require your own Supabase project; copy `supabase-config.example.js` to `supabase-config.js` and add only a Supabase publishable key. Never put service-role keys or other secrets in frontend files.

## Built with

JavaScript, HTML, CSS, Chart.js, and SheetJS.
